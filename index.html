    FAQ

    Common questions.

    What businesses usually ask us before a website project.

    How much does a website cost in Sri Lanka?

    At CobWebZ, a static website of up to five pages starts at LKR 40,000, and a full-stack web application with a database, user accounts and an admin dashboard starts at LKR 100,000. Both are one-time prices. Ongoing infrastructure, security and support is a monthly retainer, quoted to fit. Every project starts with a discovery call and a fixed, written quote. Use the estimator under Pricing for an itemised starting price.

    Do I need a static website or a dynamic web application?

    A static website suits most small businesses: a fast, secure site with a few pages and a contact form, and no server to look after. Choose a dynamic application when things need to change behind the scenes, such as user accounts, bookings or an admin dashboard where your team edits content. We build those in Python/Django or PHP with a MySQL database. Not sure? Choose “Not sure yet” in the enquiry form and we'll recommend one.

    Do you use templates or page builders?

    We don't use page builders or third-party themes. Custom sites are designed and coded for your business from scratch. If you'd like to launch sooner, you can start from one of our own hand-coded templates, which we adapt to your brand, content and photos. Either way, static sites are written in HTML, CSS and JavaScript, and web applications in Python/Django or PHP, so pages stay light and load fast.

    Will my website work on mobile phones?

    Yes. Every site we build is responsive, so the same pages fit phones, tablets and desktops. We test on all three and build to Google's Core Web Vitals thresholds, so pages stay quick on mobile data.

    Will my website show up on Google?

    Every static site we build comes with basic SEO set up: page titles, meta descriptions and image alt text, on fast, mobile-friendly code. The Advanced Technical SEO & Analytics add-on (from LKR 10,000, one-time) goes further. No one can honestly promise a #1 ranking, but a fast, well-built site gives you the best start.

    Are hosting and a domain name included?

    The Static Deployments package includes free-tier hosting on Cloudflare or GitHub Pages, connecting your custom domain and setting up SSL, so your site loads securely over HTTPS. The domain name itself, such as a .lk or .com address, is paid to its registrar. Domain, hosting and other third-party fees are billed by their providers.

    Can you build an online store?

    Yes. A store with products, a cart and orders is a dynamic web application, built in Python/Django or PHP with a MySQL database and an admin dashboard for your products. Online payments are added with Payment Gateway Setup, from LKR 25,000. For an example, see the MUTE store concept under Our Work.

    Can you add online payments, WhatsApp or more than one language?

    Yes, as add-ons to any package: payment gateway setup from LKR 25,000, WhatsApp and CRM integrations from LKR 10,000, and multilingual support (for example English, Sinhala and Tamil) from LKR 20,000. Pick the ones you want in the estimator under Pricing and the total updates as you go.

    How do you keep websites secure?

    Every site is served over HTTPS. Web applications come with secure logins and password handling, and built-in protection against common attacks such as SQL injection and cross-site request forgery (CSRF). For ongoing protection, the Enterprise Retainer adds automated vulnerability scanning, monitoring, backups and patching.

    Who looks after the website once it's live?

    That's up to you. Dynamic applications include an admin dashboard so your team can manage content. If you'd rather hand it over, the Basic Maintenance Plan (LKR 5,000 a month) covers updates, backups and uptime, and the Content Management Retainer (LKR 5,000 a month) covers four content updates or posts. Larger systems can move to the Enterprise Retainer for full infrastructure, security scanning and priority support.

    Do you work with businesses outside Colombo?

    Yes. CobWebZ is based in Colombo and works with businesses across Sri Lanka and abroad. Send an enquiry from the form below, or message us on WhatsApp, wherever you are.
